# משה קילופים — אתר חדש

אתר סטטי (HTML/CSS/JS בלבד), בלי שרת ובלי התקנות. אפשר להעלות אותו כמו שהוא ל-GitHub Pages.

## מבנה
- `index.html` — הדף
- `css/style.css` — העיצוב (הצבעים מוגדרים בראש הקובץ)
- `js/products.js` — **רשימת המוצרים והקטגוריות. כאן מוסיפים/משנים מוצר.**
- `js/app.js` — סל, הזמנה, הרשמה, היסטוריה, התקנת אפליקציה
- `img/products` — תמונות מוצרים (800px), `img/thumbs` — תמונות קטנות (320px)
- `manifest.json`, `sw.js` — התקנה כאפליקציה בטלפון

## הוספת מוצר
1. שמים תמונה ב-`img/products` ועותק קטן ב-`img/thumbs` (אותו שם קובץ).
2. מוסיפים שורה ב-`js/products.js` עם `id` ייחודי, שם, מארז, משקל המארז בק״ג (`kg`), קטגוריה ותיאור.

## בדיקה במחשב
פותחים את `index.html` בדפדפן. ההתקנה כאפליקציה עובדת רק כשהאתר עולה לכתובת https.

## אחרי עדכון באוויר
מעלים את מספר הגרסה ב-`sw.js` (`mk-site-v1` → `mk-site-v2`) כדי שהטלפונים יקבלו את הגרסה החדשה.
